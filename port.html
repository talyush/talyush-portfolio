Port Security

Understanding network entry points and attack surfaces

Ports are the doors of a system — every communication, every request, every attack starts with one of these doors. Understanding ports means understanding the "entry points" of the digital world.

What Exactly Is a Port?

A port is simply a number assigned to a process or service. When data travels across a network, ports ensure it reaches the right application.

Port Service Description
80 HTTP Unencrypted web traffic
443 HTTPS Encrypted web traffic
22 SSH Secure remote login
3306 MySQL Database server
3389 RDP Remote Desktop Protocol

Why Security Professionals Care About Ports

Because ports tell them what is running, how it communicates, and how they might break in.

  • Open ports → possible entry points for attackers
  • Closed ports → safer, but still discoverable
  • Filtered ports → firewalls are actively monitoring

Real-World Attack Examples

Port 22 open? → Brute-force SSH attacks

Port 3306 open? → Database extraction attempts

Port 21 open? → Anonymous FTP abuse

Port 445 open? → EternalBlue (WannaCry) exploitation

How Port Scanning Works

Tools like Nmap send packets to ports and analyze responses:

  • SYN scan → Stealthy & fast detection
  • UDP scan → Silent but slower detection
  • Service enumeration → "What exactly runs here?"
Security Note: Always scan only systems you have permission to test. Unauthorized port scanning is illegal in most jurisdictions.

The Core Philosophy

"If you control the ports, you control the surface."
Cybersecurity starts with knowing what's open — and why.
