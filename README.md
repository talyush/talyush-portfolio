# Talyush Portfolio

A cybersecurity-focused interactive portfolio website demonstrating technical skills through hands-on challenges.

## 🎯 Features

- **Interactive Terminal**: 1/0 logic-based navigation
- **5-Stage CTF Challenge**: Base64, ROT13, Binary, Hex, and Devtools investigation
- **Hidden Profile**: Accessible only after completing the security challenge
- **Security Education**: Google Dorking, Reconnaissance, OSINT, Port Security, XSS
- **Professional Design**: Dark theme with CRT effects and responsive layout
- **Security Hardened**: XSS protection, input validation, buffer overflow prevention

## 🚀 Live Demo

**[https://talyush.github.io/talyush-portfolio/](https://talyush.github.io/talyush-portfolio/)**

## 🛠️ Tech Stack

- HTML5, CSS3, JavaScript
- xterm.js for terminal emulation
- Canvas API for Matrix rain effect
- LocalStorage for session management
- Base64, ROT13, Binary, Hex encoding/decoding

## 🔐 Security Features

- XSS protection via HTML escaping
- Input validation and sanitization
- Buffer overflow prevention
- LocalStorage-based session management
- No external dependencies (except CDN for xterm.js)

## 🎮 CTF Challenge Guide

The CTF challenge consists of 5 stages:

1. **Stage 1**: Base64 decoding
2. **Stage 2**: ROT13 deciphering
3. **Stage 3**: Binary translation
4. **Stage 4**: Hexadecimal conversion
5. **Stage 5**: Source code investigation (Devtools)

Complete all stages to access the hidden profile with detailed information.
